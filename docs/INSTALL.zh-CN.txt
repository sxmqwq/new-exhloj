Extend HLOJ 2.3.2

安装与升级
1. 推荐在 Tampermonkey 中编辑现有脚本，清空旧内容并替换为本包 .user.js 的全文，再保存。这样能保留原来的设置和缓存。
2. 若作为新脚本安装，请先停用旧版，避免同时运行。脚本名称为 Extend HLOJ；文件名不再带 -core-ui。
3. 新安装与旧安装的油猴存储可能彼此独立。可先在旧版导出 JSON 备份，再在新版控制面板导入。
4. 刷新 OJ。右上角用户菜单、页面右下角备用按钮及油猴菜单均可打开控制面板。面板标题应显示 2.3.2。

现有模块
core、ui、captcha、remote-problem、contest-helper、juan-monitor、user。
保留 2.1.1 的验证码识别和折叠修复，可点击按钮重新展开。
不连接原插件的旧后端；设置和快照保存在当前浏览器的油猴存储。

user（本地用户模块，2.3.0 新增）
用户菜单或控制面板 → 用户工具。没有特定 UID 的管理员限制；普通用户和未登录状态均可编辑本地数据。
资料只影响本机显示，不修改 OJ 用户名、角色或站点认证。读取 OJ 榜单和用户名仍以站点实际开放的数据为准。
- 七种名字显示模式：原样、姓名、用户名、姓名（用户名），以及对应颜色模式；可独立显示 CCF 级别标记。
- 可编辑任意 UID 的姓名、用户名、教练标记、OIerDB ID、CCF 级别、高中毕业年份、题目分、获奖记录。
- 个人主页显示本地信息卡、获奖记录、Rating 历史和 OIerDB 链接。
- 初始 Rating 为 1800，沿用原版的等级颜色；支持当前 Rating、历史最高、最后 20 场上分/下分排行榜，同分并列。
- Rated 比赛榜单显示表现分和 Rating 变化；同一页面重复更新时不会重复插列。
- 用户资料和 Rating 可单独导入/导出 JSON，也包含在控制面板的完整备份中。支持旧版 exhloj.user、exhloj.ratedcontests 缓存和姓名显示选项。
- “从卷王统计更新题目分”将本次完整统计中的去重 AC 数写入本地资料；需手动点击，不会上传。
首次安装没有旧服务中的名单或比赛记录，需要导入已有缓存或在用户工具中填写。

2.3.2：用户链接与 CCF 徽章修复
姓名显示只修改用户名，不改写网站自带的 LV 等级/角色徽章或纯头像链接。
CCF 标记恢复为齿边认证徽章 SVG，3–5 级绿色、6–7 级蓝色、8–10 级金色。

2.3.1：资料栏位置与 OIerDb 粘贴识别
用户信息与“拥有权限”放在个人主页最外层侧栏，不再进入“通过的题目”内部的四栏排版中。
用户工具 → 编辑资料 → 粘贴 OIerDb 选手页面。复制姓名、选手信息和获奖表格后粘贴，支持：
- 网页复制的 HTML 表格；
- 浏览器复制的制表符或逐单元格换行文本；
- Markdown 表格（包含链接、奖牌和加粗均可）。
粘贴后自动填入姓名、CCF 等级、按学年换算的高中毕业年份、OIerDb 排名/积分和获奖记录。当前年级按北京时间每年 9 月换学年。
分数的小数、满分、比赛排名与人数、省份、学校、参赛年级、比赛与学校 ID 会保留。识别到的奖项替换表单中的获奖列表；有无法识别的行会在提示中列出数量。
OJ 用户名、教练标记和题目分保留。没有识别到的字段保留原值。粘贴不会自动保存，核对后点击“保存本地资料”才生效。
页面内容通常不带选手自身的 ID；OIerDb 排名、比赛 ID、学校 ID 都不会被当成选手 ID。需要时在可选链接栏粘贴 https://oier.baoshuo.dev/oier/数字ID，再点击“识别并填入资料”。
所有识别在本机完成，不请求 OIerDb、GitHub、图片或旧后端；复制内容中的脚本不会执行。

Rated 比赛本地结算
用户工具 → Rated 比赛与结算。命令格式：
  version:2
  contest:test/比赛ID,比赛标题,1
  rating:test/比赛ID
域名和比赛 ID 填实际值。点击结算才 GET 读取对应 OJ 榜单，计算成功后整体替换本地 Rating。
version:1 只纳入正分选手；version:2 纳入所有有提交且有排名的选手。未写 version 时按旧版默认值 1 处理。
contest 行第三项为权重，范围 0–10。第四项可提供 [[UID,排名],...]，例如：
  contest:test/123,Example,1,[[7,1],[8,2]]
提供名次后，无需请求 OJ；也支持旧版以连字符代替 JSON 逗号的名次格式。
同一 rating 行可用逗号连接多场比赛，按原版逻辑并行结算，对每人采用加权变化最大的场次，再执行组内校正。
可保存命令草稿。没有读取权限、命令错误、超出请求限额或取消时保留原有 Rating；不会调用旧后端更新姓名、教师身份或 Rating。

contest-helper（比赛助手）
在用户菜单或设置中打开；比赛/作业详情与榜单页也有入口。
可选择域、比赛或作业 ID，导出：
- 题面 ZIP：优先中文题面，按 A/B/… 分目录，可下载题面引用的附加文件和公开比赛附件；引用路径改为包内相对路径。
- 提交 CSV/JSON：分页读取并按提交时间排序；可选逐条读取用时、内存和测试点详情。
- Ghost：导出比赛、题目、选手及提交记录。
导出尊重账号现有权限。灵活计时比赛须先在原站开始。
附件依赖浏览器可访问的下载链接；跨域下载还受 CORS 限制。缺失题目或附件会记录在 REPORT.json；缺失题目另有 ERROR.txt。
提交导出不包含源码。未开放的字段保留空值，不推算隐藏成绩。

报名
自动报名默认关闭。设置 → 比赛助手/监视器参数可填写：
  test/contest
  test/homework
每行一个目标，可设置标题包含文字、允许赛制和检查间隔。
在比赛助手中点击“检查待报名”只执行读取；可逐项点击“报名”。
只有明确启用“自动报名”后，脚本才定时检查配置的目标并提交报名。
自动报名使用普通文本筛选，不执行旧版配置中的 JavaScript。

juan-monitor（卷王监视器）
填写训练域 ID，或点击“读取可访问域”后选择域。
选择公开 AC 提交、比赛榜单、作业榜单及近期范围，点击“开始统计”。
同一用户在同一域通过同一题只计一次。榜单按原始分数满分判断，不把最高的部分分当作 AC。
区间 AC 按可见的 AC 提交时间统计；没有可见提交时间的榜单结果仅计入累计数。区间 AC 可以包含区间内重复通过的旧题，不等同于首次通过题数。
每次完整扫描保存本地快照；“较上次新增”与同一账号、同一域集合和同一来源组合的完整快照比较。首次扫描显示 —。
权限错误、分页重复、请求/页数超限、取消任务都会显示不完整；保留已读取的部分结果，不写入完整快照。
可导出 CSV/JSON、复制榜单。显示前 100 人，导出包含全部结果。
本版使用实际去重题数，不沿用旧版针对特定训练域的加权分数，也不调用旧后端发布练习分。

请求控制
导出和统计串行请求，默认间隔 250 毫秒，每类列表最多 100 页，单次任务最多 2000 次请求。可在参数中调整，运行中可取消。
自动报名默认关闭，监视器手动启动。单个附件限制为 64 MiB。
题源模块按原有设置读取洛谷/Codeforces/QOJ，不依赖旧插件后端。验证码本地识别，不自动提交登录。

验证范围
61 组 Chromium 浏览器场景通过，OJ 接口使用模拟响应；包含题面 ZIP 的 CRC、UTF-8、二进制附件和缺失报告验证。
user 验证涵盖任意 UID 本地编辑、姓名显示还原、旧缓存与备份、排行榜、榜单动态更新、双人参考 Rating、并行结算、取消、权限错误和请求限额。
新增检查使用用户提供的 24 条 OIerDb 获奖示例，并覆盖嵌套侧栏、HTML/普通文本粘贴、小数分数、学年切换、ID 区分、不完整输入及保存前不写入。
保留此前基于实际 SVG 的验证码检查及题源响应格式检查。
当前环境未完成 HLOJ 登录态实测；站点特有字段或权限差异仍需实际账号验证。
第三方许可证见 THIRD_PARTY_NOTICES.txt，脚本内亦附有许可证。
