Extend HLOJ 2.8.0

安装与更新
1. 安装 Tampermonkey：https://www.tampermonkey.net/
2. 打开 https://raw.githubusercontent.com/sxmqwq/new-exhloj/main/dist/exhloj.user.js ，按提示安装或更新。
3. 刷新 OJ，在用户名菜单中点击 Extend HLOJ；没有用户名菜单时使用右下角入口。
离线安装可下载发布页中的安装包，解压后安装 .user.js 文件。
发布页：https://github.com/sxmqwq/new-exhloj/releases/latest
更新现有脚本会沿用本地设置与资料。面板标题中可查看当前版本。

统一控制面板
首页提供常用入口，顶部导航可以在比赛、卷王、用户、题源、设置、数据之间切换。
题目页、比赛页和个人主页的快捷按钮会打开同一个面板中的对应工具。

比赛
可导出题面和附件 ZIP、提交 CSV / JSON、Ghost。提交记录导出不含源码。
填写比赛或作业的域、类型和 ID；在对应页面打开时会自动带入。
公开附件按原目录打包，缺失内容会写入包内的报告。

自动报名
比赛 → 自动报名设置。填写目标，每行一项，例如：
  pnoi/contest
  pnoi/homework
可填写标题必须包含的文字、允许赛制（例如 oi,acm）和检查间隔。
勾选启用并保存，保持 OJ 登录且开着一个 OJ 页面。
“检查待报名”可查看匹配结果。已结束或已经报名的比赛会跳过。

卷王
选择训练域、提交与榜单来源，点击开始统计。
同一用户在同一域通过同一道题只计一次。可查看近期 AC、累计 AC 与快照变化，并导出结果。
只有完整扫描才保存新快照；失败或取消时会显示已读取的部分结果。

用户资料与 OIerDb
用户 → 编辑资料。输入 OJ 用户 ID，可管理本地姓名、用户名、教练标记和题目分。
在 OIerDb 导入框粘贴 https://oier.baoshuo.dev/oier/选手ID 形式的主页链接。
读取后检查资料并保存，选手 ID 会一并记录。已绑定资料支持单人或批量刷新。
刷新只更新 OIerDb 字段，保留 OJ 用户名、教练标记、题目分和 Rating。

快捷导入
用户 → OIerDb 快捷导入。读取所选域的排名页，在本地匹配姓名或拼音。
命中 1–3 人时进入候选；多候选可展开查看并选择一人，由你确认后保存。
每轮扫描共用一份数据库，不会按用户名反复下载。候选不会自动写入资料。

比赛 Rating
比赛详情或榜单页 → 加入 Rating 并结算，自动添加当前比赛并结算。
普通结算从已保存的分数继续，只追加新比赛；重复比赛会跳过。
比赛、用户页面中均可打开时间轴：选日期、读取比赛、勾选后从 1800 重新结算。
时间轴按比赛开始日期筛选已结束的比赛（包括首尾日期，使用浏览器时区），按开始时间依次计算。
时间轴成功后会替换全部 Rating 历史，只保留所选比赛；失败或取消时保留原数据。

用户 → Rated 比赛与结算也支持命令：
  version:2
  contest:pnoi/比赛ID,比赛标题,1
  rating:pnoi/比赛ID
第三项为权重。version:2 纳入有提交且有名次的选手；version:1 只纳入正分选手。
算法、并行组和边界规则见 docs/RATING.zh-CN.md。

题源与难度
点击“按题意搜索原题”，编辑当前题面或输入简述，勾选原题机、CPRet 后开始搜索。
只在点击后将输入框内容发送到勾选的网站，不发送 OJ 账号或 Cookie。
结果按网站分别排列；可查看候选题意、打开原题、展开同组候选。
核对题意、数据范围和样例后，点击“核对并关联”，检查配置，再“确认并保存题源”。
搜索和选择候选不会自动覆盖已有题源；确认的关联只保存在本地。
长题面建议自行简述。原题机最多 16000 字符；CPRet 最多处理 2048 token，并有查询链接长度限制。
单站失败不影响另一站，可停止、重试，也可复制题意后打开检索网站。
题目页自动识别已配置的远程题源；题名中的 [QOJ18209] 等标记可作为默认 QOJ 题源。
可以读取洛谷难度、翻译和题解，并导出已加载内容。
“配置题源”可修改本机映射、手动选择难度；选择“跟随原站”可取消手动覆盖。
洛谷难度使用新版体系，包含青色“提高”，紫色编号为 7，黑色编号为 8。
比赛中的题源显示方式可在设置中选择隐藏、Ctrl+Q 显示或始终显示。

设置
可调整界面增强、验证码折叠、姓名显示以及 CPH / CP Editor 端口。
验证码无法识别时保留手动输入；识别后可点击展开。

数据与备份
“导出完整备份”保存设置、题源配置、用户资料和 Rating。
也可仅导出用户与 Rating。选择 JSON 文件或粘贴备份内容后导入。
数据保存在当前浏览器中，更换浏览器或电脑时可通过备份迁移。

遇到问题
先核对面板中的版本，使用“数据”中的故障信息辅助反馈。
